# kucse-b9-day2


## Steps
- Create a folder (e.g: practice2)
- Open a COmmand Prompt Terminal
- Check python version (`python -V`)
- Install Virtual env (`pip install virtualenv`)
- Create Virtual env (`python3 -m venv .venv`)
- Actiave the virtualenv (`source .venv/bin/activate`, `.\.venv\Scripts\Activate.bat`)
- Install DJango (`pip install Django`)
- Check Version of Django (`python -m django --version`)
- Create a Directory (`mkdir djangotutorial`)
- Create Django Project (`django-admin startproject mysite djangotutorial`)
- Change Directory to `djangotutorial` (`cd djangotutorial`)
- Run server (`python manage.py runserver`)
